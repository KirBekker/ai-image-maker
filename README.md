# AI Image Maker

Codex skill for creating and editing AI-generated visuals for client websites, campaigns, and project assets.

## Install

Copy this folder into your Codex skills directory, then invoke it with `$ai-image-maker`.

The [source index](references/sources.md) contains dated vendor documentation and research references from 2025–2026. Research papers marked as arXiv preprints are provisional and should not be treated as production requirements.
